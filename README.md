# Recipe Finder Frontend 🍽️

A responsive Recipe Finder Web Application built using HTML, CSS, JavaScript, and API integration.

## Live Demo

🔗 https://recipe-finder-frontend-amber.vercel.app/

## Features

- Search recipes by name
- Filter recipes by cuisine
- Filter recipes by meal type
- View detailed recipe information
- Display ingredients and cooking instructions
- Responsive design for mobile, tablet, and desktop

## Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)
- DummyJSON Recipe API
